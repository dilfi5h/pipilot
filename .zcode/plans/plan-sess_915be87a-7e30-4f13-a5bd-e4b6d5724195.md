# Logo 配色预览页计划（PiPilot / 黑底×多字色×多字体）

## 用户已定
- 内容：纯 Π 大字（大写希腊字母 U+03A0），不加 PiPilot 组合、不做多尺寸
- 范围：统一纯黑底，只变换 Π 字色（基准蓝 + 系列变体）
- 字体：同一配色多字体/粗细并排对照
- 交付：传到 deb 机器 `/root/vps/www/logo.html` 后浏览器看效果

## 1. 新建本地文件（1 个文件，不碰现有代码）
- 路径：`C:\Users\Administrator\appi\logo.html`（暂存 staging 文件，选定 logo 前不提交 git；现状无 remote、main 只有单根提交 5fd8633，保持 clean）
- 单文件自包含：全部 inline `<style>`，零外部字体/JS/CSS，避免 services.gradle 式裸连卡死和 GFW 字体加载失败；只用系统字体栈

## 2. 页面结构
- 页底深灰（#111），标题一行：`PiPilot Logo — Π / 黑底×多字色预览`
- 网格：每行 = 一种字色 × 黑底卡（#000），卡内并排 3 个 Π（同一颜色、不同字体）：
  - A：无衬线 Bold（系统黑体，呼应 App 标题栏 SemiBold）：`font-family: system-ui, "Segoe UI", Roboto, "Noto Sans", sans-serif; font-weight: 800`
  - B：无衬线 Black 最粗：`font-weight: 900; letter-spacing` 同 A，用于看小尺寸/加粗上限
  - C：衬线 Bold 对照：`font-family: Georgia, "Noto Serif", serif; font-weight: 700`（只做点缀，不做主标候选）
  - 字号统一约 96px，卡下标注：颜色名 + hex + 字体名
- 字色清单（12 块，首块为基准蓝）：
  1. 基准蓝 #2E9BFF（用户说的黑底蓝字起点）
  2. 天空蓝 #38BDF8，3. 青 #22D3EE，4. 品蓝 #4D9FFF（偏紫的蓝对照）
  5. 绿 #4ADE80，6. 青柠 #A3E635（和终端绿 0xFF9CCC65 呼应的冷暖对照）
  7. 黄 #FACC15，8. 品牌橙 #FF7043（Theme.kt PiOrange，现 launcher/primary 色，做参照）
  9. 红 #F87171，10. 紫 #A78BFA，11. 粉 #F472B6，12. 纯白 #FFFFFF（夜间最高对比参照）
- 顶部加一行说明条：`背景统一 #000000；Π 为 U+03A0；橙色为现有 PiOrange 参照`

## 3. 上传到 deb（沿用已验证通道）
- deb 直连（`deb.871116.xyz` 不在 `~/.zcode/gfwdomains.txt`，`~/.ssh/config` Host deb 无代理）：**不走 socks 代理**
  - `scp "C:/Users/Administrator/appi/logo.html" deb:/root/vps/www/logo.html`
- 校验（两端 md5 必须一致）：
  - 本地 `md5sum` + `ssh deb "md5sum /root/vps/www/logo.html; ls -l /root/vps/www/logo.html"`
- 超时/后台坑（记忆已有）：scp 到 deb 常静默转后台 ~30s，按分阶段轮询；单条命令超 1 分钟无输出直接 kill，排查后重试，禁止裸连死等；远端磁盘 5.2G 余量，小文件无压力

## 4. 验收
- 远端 md5 一致后给用户 URL：`http://deb.871116.xyz/logo.html`（与 `dl/` 同属 `/root/vps/www` 静态根；若站有 https 则同路径 https 访问）
- 用户在浏览器里选定 1 个字色（+ A/B/C 哪个字体）后，下一步再按此做正式 launcher/icon，不在本次做

## 风险/不做
- 不改 `res/`、`Theme.kt`、不加依赖；Π 字形在不同手机字体下渲染略有差异， serif C 列仅预览用
- 若 www 根另有 nginx 鉴权导致外网打不开，回退为 `ssh deb "python3 -m http.server"` 临时看或直接看本地文件，不改服务器配置
